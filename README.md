## 👋 Halo!

Sejak tahun 2021, saya mulai belajar R. Berawal dari iseng-iseng, akhirnya semakin tertarik untuk mengenal R lebih jauh. Website ini adalah tempat saya mendokumentasikan perjalanan belajar, berbagi pengetahuan, dan mengeksplorasi keindahan data melalui visualisasi.

## ✨ Apa yang Saya Bagikan?

### 📊 [Galeri](https://panggahdputra.com/galeri/)
Koleksi visualisasi data dari berbagai dataset menarik, termasuk:
- **TidyTuesday Projects** - Eksplorasi mingguan dengan data dari berbagai topik
- **Kenya Census Analysis** - Analisis demografis Kenya
- **Survivor TV Show** - Visualisasi data reality show ikonik
- **Ask Manager Salary Survey** - Insights tentang gaji di berbagai industri
- **Transit Cost Project** - Perbandingan biaya transportasi global
- Dan masih banyak lagi...

### 📐 [Katalog](https://panggahdputra.com/katalog/)
Panduan dan template untuk 30+ jenis visualisasi data, dari yang sederhana hingga kompleks:
- Bar & Column Charts
- Scatter Plots & Bubble Charts
- Distribution Plots (Histogram, Density, Violin)
- Specialized Charts (Bump, Beeswarm, Ridgeline)
- Dan berbagai jenis visualisasi lainnya

### ✍️ [Artikel](https://panggahdputra.com/artikel/)
Tulisan tentang data science, R, dan hal-hal yang saya pelajari di sepanjang perjalanan, seperti:
- Anscombe's Quartet
- Antara Sains dan Seni (dalam visualisasi data)
- Review buku yang saya baca

## 🛠️ Tech Stack

Website ini dibangun dengan **R**, **blogdown**, dan **Hugo** - kombinasi sempurna untuk data scientist yang ingin berbagi karya dan pengetahuan.

## 💡 Filosofi

*"Adalah hal yang menyenangkan, dapat berbagi segala sesuatu yang telah kita pelajari."*

Saya percaya bahwa belajar adalah perjalanan yang lebih bermakna ketika dibagikan. Melalui website ini, saya berharap dapat menginspirasi orang lain untuk mulai belajar R dan visualisasi data.
